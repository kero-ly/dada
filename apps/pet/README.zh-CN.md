# 桌宠

使用 `contracts/app.h` 的、与硬件无关的原生 C 应用。
English: [README.md](README.md)。

让一个角色在屏幕上"活着"：会呼吸、按住屏幕会下沉、偶尔左右晃一下。
全部由 `time` 契约驱动，所以在完全没有触摸的板子上也能跑。

- 呼吸：3 秒一个周期、幅度 6 像素的三角波，刷新时施加。
- 按压：整个人下沉 6 像素，松手缓动回位。
- 小动作：每 8–20 秒左右挪 1 像素，然后归位。
- 帧来源：storage 里的 `pet.frame` 优先，否则用 `apps/app_support/portrait/`
  里的共享内置帧。
- 需要 RGB565 显示（≥200×200）和 `time`；input 与 storage 可选——
  没有 input 就只是不会对触摸有反应。

## 为什么用位移而不是多画几帧

160×120、15 色下，多一个姿态就是 9.6 KB。呼吸用像素位移实现不占帧预算，
观感也对，所以帧预算留给表情更划算。

注意画面是**旋转**到竖屏面板上的：用户看到的上下运动对应**逻辑 y** 的偏移。
这个轴弄反，桌宠就会左右平移而不是上下呼吸。

```sh
pio run -d firmware -e dada-c3-pet
pio run -d firmware -e dada-s3-pet      # 微雪 S3 板，无触摸
```
