# 像素头像

使用 `contracts/app.h` 的、与硬件无关的原生 C 应用。
English: [README.md](README.md)。

显示一张 160×120、15 色的已存帧，旋转后铺满竖屏面板——把板子横过来看就是正的。

**本仓库不包含任何图片素材。** 帧是第三方同人图，所以应用从 storage 读取，
没有数据时画一块纯色占位。这样 CI 构建仍然有意义，仓库也不带没有分发权的图片。

- 帧格式：160×120 格、4 bit/格（9600 字节），调色板与 `paint` 相同。
- 存在 NVS 命名空间 `dada` 的 `whale.f0` 下。
- 想放自己的图：用 `paint` 画一张，或者用脚本生成打包帧，写入 `whale.f0` 一次即可。
  长度与网格不符的帧会被拒绝。
- 渲染按 8 行条带进行（3.8 KB），而不是申请整块 240×320 帧缓冲（150 KB）——
  后者在有其他数据驻留时拿不到连续内存。
- **未实现眨眼**。三帧过渡和"画眼皮"两种做法最后都变成头发上的一块浅色方块；
  要做得自然，需要手绘闭眼帧。

```sh
python tools/dada.py build --app whale
python tools/dada.py flash --app whale --port YOUR_PORT
```
