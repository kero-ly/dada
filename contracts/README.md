# 能力与应用契约

- `display.h`：RGB565 像素输出与背光控制，不含 UI 控件或绘图原语。
- `input.h`：指针坐标、按压状态和样本有效性，不含手势识别。
- `app.h`：实验性单应用生命周期，借用显示/输入服务；由固件入口调度和清理。
- `schema/board.schema.json`：板级清单校验；`tools/gen_board_config.py` 在构建期生成配置头文件。

应用不能绕过契约访问 GPIO、ESP-IDF 或板卡名字。板级绑定提供契约实现。
`app.json` 当前只登记原生 C 应用格式、所需能力与最小屏幕尺寸，完整版本兼容与资源匹配待后续验证。
板级声明、编译通过与实机验证是不同证据；null 仍表示未知，不能用宣传参数代替实测。
