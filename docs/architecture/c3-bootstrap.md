# C3 工程基线 · 2026-10-24

用户已购买金逸晨 ESP32-C3 2.4 寸触摸板，要求初始化工程并准备由用户推送到 GitHub。此前 HTML 中的 S3 优先采购路线不再作为当前执行计划。

沿用已讨论的应用 / 平台 / 板级适配边界，采用单仓库和 PlatformIO 管理的 ESP-IDF 集成工程。PlatformIO 统一版本、依赖和环境入口，底层仍是原生 ESP-IDF 构建。

本次工程选择 PlatformIO Core 6.2.0 的 Espressif32 6.8.1 平台提供的 ESP-IDF v5.3.0 作为明确基线（非对最新版本的判断）。卖家源码尚未检查，因此不承诺驱动与该版本兼容；版本变更须同步本地文档、CMake 检查和 CI 镜像。

范围：串口启动骨架、按职责划分的目录、硬件登记草案、CI 编译配置、团队协作与实机验收说明。平台接口、外设驱动、番茄钟和 AI 功能均待后续实现。未知 GPIO/触摸/Flash 不填猜测值。

本轮完成标准：仓库结构与配置自洽，Git 已初始化，用户可自行提交推送。完整编译和烧录必须单独报告，不将静态检查视为运行验证。
