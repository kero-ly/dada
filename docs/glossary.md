# 术语表 / Glossary

中英对照，防止翻译漂移。**代码里的标识符一律用英文**，文档两种语言都引用同一张表。

| English | 中文 | 定义 | 不要译成 |
| --- | --- | --- | --- |
| capability | 能力 | 板子能对外提供的一类功能，如 `display`、`input`、`time` | 功能、特性 |
| capability contract | 能力契约 | 定义能力的最小 C 接口，sink 级，不含绘图原语 | 接口协议、API 规范 |
| board manifest | 板级清单 | `board.json`，一块板的唯一真源 | 板子配置文件、硬件描述文件 |
| board binding | 板级绑定 | 把清单里的引脚/参数接到具体驱动的代码层 | 板级适配层（容易和 BSP 混） |
| BSP | 板级支持包 | 针对某块板的初始化与资源声明 | — |
| component | 组件 | 可复用驱动单元，实现某个契约 | 模块、插件 |
| runtime | 运行时 | 生命周期、能力发现、资源仲裁 | 运行库、框架 |
| app | 应用 | 只依赖契约与 UI 运行时的业务代码 | 程序、软件 |
| IR | 中间表示 | 应用的声明式描述（YAML） | 中间件、配置格式 |
| codegen | 代码生成 | 构建期把清单/IR 展开成 C 代码 | 编译 |
| verify | 验证 | 在真实硬件上跑自检并产出报告 | 测试（测试更泛） |
| verification report | 验证报告 | `dada verify` 输出的 JSON + 人读记录 | 测试报告 |
| provenance | 证据来源 | 某个事实的可信度等级（卖家页/规格书/原理图/实测） | 出处、来源（太泛） |
| sink-level | sink 级 | 只接收数据并输出到设备，不含高层语义 | 底层、驱动级 |
| escape hatch | 逃生舱 | 允许在声明式应用里嵌入少量 C 的 `native:` 块 | 后门、扩展点 |
| bring-up | 点亮 / 上电调试 | 让一块新板从零到能跑的最小验证过程 | 启动、引导 |
| panel | 面板 | 屏体 + 驱动 IC 的组合 | 屏幕（口语可，正式用面板） |
| flush | 刷屏 | 把像素缓冲区送到面板 | 刷新、推送 |
