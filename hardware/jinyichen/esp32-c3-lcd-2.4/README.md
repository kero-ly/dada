## 接入前收集

- 实物正反面照片、PCB 丝印与修订号。
- 原理图、GPIO 表、Flash 容量、屏幕背光/复位接线。
- ST7789 初始化参数、色序、方向与偏移；屏幕 SPI 接线。
- 触摸控制器型号、总线地址、复位/中断接线与坐标变换。
- USB 是原生 Serial/JTAG 还是桥接芯片，C-to-C 支持情况。
- 厂商可编译源码、工具链版本与许可证；只拿到二进制不算驱动交付。
