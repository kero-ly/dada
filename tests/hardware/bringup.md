# C3 首板验收

每次验证复制 record-template.md 为独立记录，附提交 SHA、板卡修订、SDK 版本及日志。不要提交设备密钥、个人串口标识或网络凭据。

1. 确认外观、USB 接口、电源、Flash 及原厂固件备份/恢复方法。
2. 编译串口 smoke 固件，记录构建成功与二进制大小。
3. 烧录并看到 `C3 bootstrap ready`，连续重启 3 次确认。
4. 驱动接入后验证屏幕纯色、边界、方向、色序；当前未实现。
5. 验证触摸四角、中心与释放事件，检查坐标映射；当前未实现。
6. 番茄钟实现后验证开始、暂停、重置、倒计时结束与持续运行；当前未实现。

编译成功不能替代第 3–6 项。当前没有自动化硬件测试。
